## S1 — Postgres, pgvector, row-level security

**Goal:** the schema every later slice writes into, with tenant isolation enforced by the
database rather than by application code that can forget.

### Deliverables

- `packages/db` — an eighth package (ADR 0001). Owns the async engine, the org-scoped
  session, the SQLAlchemy 2.0 models and the Alembic migrations.
- `org_id` denormalised onto `chunks` and `document_acl` with a composite FK back to
  `(documents.id, documents.org_id)`, so a chunk cannot point at another org's document
  (ADR 0002). §8 keys both on `document_id` alone yet also requires RLS keyed on
  `org_id`; those cannot both be literally true.
- Migration `0001` — hand-written, not autogenerated: `CREATE EXTENSION vector`, the
  fifteen tables, the HNSW index (`m=16, ef_construction=64`, built empty), RLS
  enable + **force** + policies, and `CREATE SCHEMA langgraph`. `downgrade()` is real.
- `engine.py` — `org_session()` is the only sanctioned way to open a session.
- `infra/docker/initdb/01-app-role.sql` — the restricted `jutsu_app` role, plus the
  `jutsu_test` database.
- CI gains a `pgvector/pgvector:pg16` service container, the restricted role, and an
  assertion that the DB suite did not skip.

### Three things that had to be found by running it

Each of these looks correct on the page and is inert or broken in the database.

1. **`SET LOCAL app.current_org_id = :org` is a syntax error.** `SET` is a utility
   statement and takes no bind parameters, so the org id would have to be concatenated
   into SQL — with a value that arrives from a request context. `set_config(name, value,
   true)` is the function form: transaction-scoped *and* parameterisable.
2. **The dev role is a superuser, and superusers bypass RLS unconditionally.**
   `FORCE ROW LEVEL SECURITY` does not help — FORCE only covers the table *owner*.
   Connecting the application as the bootstrap role leaves every policy silently inert
   and every isolation test green against nothing. Hence the split roles, and
   `test_app_role_cannot_bypass_rls`, which fails if that ever regresses.
3. **`current_setting(.., true)` returns NULL only until the GUC has been set once.**
   After any `set_config`, a later transaction reads an empty string instead, and
   `''::uuid` raises rather than filtering — turning a fail-closed policy into a hard
   error. The predicate wraps it in `NULLIF(.., '')`.

### Gate S1 — run 2026-08-19 against Postgres 16 + pgvector 0.8.6

1. `make up` — Postgres, Neo4j, Redis healthy.
2. `make migrate` — 0001 applies cleanly to an empty database.
3. `uv run pytest packages/db -q` — 22 passed, **0 skipped**.
4. `make migrate-down` then `make migrate`; the `pg_catalog` fingerprint test proves the
   schema comes back identical.
5. `ix_chunks_embedding_hnsw` present with `m=16, ef_construction=64`; `embedding` is
   width 768; `relrowsecurity | relforcerowsecurity` is `t | t` on all three tables.
6. Cross-org isolation demonstrated as `jutsu_app` (`rolsuper=f`, `rolbypassrls=f`): the
   same `SELECT count(*) FROM documents` returns 1 under each org scope with disjoint
   titles, 0 unscoped, and an insert carrying another org's `org_id` is rejected by
   `WITH CHECK`.
7. `make preflight` green — 53 tests, 0 skipped.

## Notes carried into Phase 1

- **Bitemporality starts at migration 001** (§7). `packages/graph/temporal.py` with
  `supersede()` and `as_of()` is written in S2, before there is anything to store. Retrofitting
  it in week 8 means rewriting every edge and template, and the decision ledger is worthless
  without it.
- **Enron sampling takes complete threads**, never random messages (§19). The sampler emits
  `sample_manifest.json`; the same seed must produce a byte-identical manifest.
- **PII masking is the hardest correctness problem in the ingestion path** (§9.1). Its ten tests
  are written *before* the implementation, and they include the non-ASCII case — character
  indices, not byte indices.
